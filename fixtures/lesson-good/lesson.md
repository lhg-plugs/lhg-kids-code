# 《循环：小猫的复读机》教案

> 年龄段：8-10岁 | 工具：Python（turtle） | 课时：45分钟 | 所处阶段：用

## 教学目标

1. 学完后孩子能说出"循环就是把一件事重复做 N 次"。
2. 学完后孩子能把示例中的重复次数从 4 改成 6，并说清图形发生了什么变化。

## 故事引入

小猫洗了 10 个盘子，每个盘子都要"冲水、擦干、放好"。
洗到第 3 个，它叹了口气："能不能说一遍，让它自己重复 10 次？"
提问钩子：如果你是小猫，你会怎么跟"复读机"下命令？

## PRIMM 五步

### 1. 预测（5 分钟）

给孩子看下面的代码，不许先运行，猜猜会画出什么：
A. 一条直线  B. 一个正方形  C. 一个圆

```python
import turtle  # 请出画画的小乌龟

turtle.speed(6)  # 小乌龟跑快一点
turtle.pencolor("blue")  # 拿起蓝色的画笔

for i in range(4):  # 复读机说：下面两行，做 4 遍
    turtle.forward(100)  # 往前爬 100 步
    turtle.right(90)  # 向右转一个直角弯

turtle.done()  # 画完了，窗口留着给我们看
```

### 2. 运行（5 分钟）

老师先运行一遍。运行后你会看到：蓝色正方形，一笔一笔画出来。
若结果不符，先检查：缩进是否为 4 个空格、冒号后是否换行。

### 3. 探究（10 分钟）

追踪表：`i` 从 0 数到 3，每数一次画一条边。提问链：
"如果 `range(4)` 改成 `range(3)`，会画出什么？"
"转 90 度改成 120 度，4 条边还能接上吗？"

### 4. 改写（10 分钟，一次只动一处）

1. 把 `4` 改成 `6`：看看图形变成了什么。
2. 把 `"blue"` 改成 `"red"`：颜色变了，形状变了吗？
3. 把 `100` 改成 `50`：图形变小了，边数变了吗？

### 5. 创造（10 分钟，给脚手架）

脚手架：上面的代码只改数字和颜色，画一个"属于你的图形"，
画完后用一句话说说你让复读机重复了什么。

## 课堂互动小游戏

**游戏名**：人体复读机（8 分钟）
**规则**：
1. 老师喊"复读机说：拍手 3 次"，全班一起拍 3 次。
2. 老师只说动作不说次数时，大家要问"重复几次？"。
3. 请一位孩子当"小老师"下命令，其他人执行。
4. 答错不扣分，错了就一起再来一遍。
**安全注意**：原地活动，不跑动；声音控制在室内音量。

## 课后练习

- **必做**：把课堂代码的边数改成 5，画出来，家长帮忙拍照记录。
- **挑战**：试试 `range(4)` 配 `right(90)` 以外的组合，看看能画出什么新图形，
  做不出来很正常，下节课我们一起做。
